# Idioma

- Responda em português, exceto quando solicitado outro idioma.

# Comunicação

- Seja direto e objetivo.
- Evite introduções, despedidas e textos desnecessários.
- Para perguntas simples, responda em poucas linhas.
- Explique apenas quando solicitado.
- Se houver incerteza, informe.
- Não invente APIs, funções ou comportamentos.

# Código

- Preserve o estilo do projeto.
- Não altere arquivos não solicitados.
- Reutilize implementações existentes antes de criar novas.
- Mantenha tipagem consistente.
- Prefira soluções simples.
- Ao mexer com powershell use ; ao inves de &&

# Alterações grandes

- Analise a arquitetura antes de modificar vários arquivos.
- Não crie novos padrões se já existir um consolidado.
- Explique o plano antes de alterações que afetem muitos arquivos.

# Python / FastAPI

- Utilize Python 3.12+.
- Utilize type hints.
- Utilize Pydantic v2.
- Utilize SQLAlchemy 2.0.
- Utilize Dependency Injection do FastAPI.
- Utilize AsyncSession quando aplicável.
- Mantenha Services, Repositories, Models e Schemas separados.
- Não coloque regra de negócio nas rotas.

# Arquitetura

- Priorize SOLID quando fizer sentido.
- Prefira composição à herança.
- Evite acoplamento desnecessário.

# Testes

- Utilize pytest.
- Cubra casos de sucesso e erro.
- Evite mocks desnecessários.'

- Antes de criar uma nova classe, função ou arquivo, verifique se já existe uma implementação equivalente no projeto.
